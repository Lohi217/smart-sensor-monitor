# Smart Sensor Monitoring & Alert System

## 📌 Project Description

The Smart Sensor Monitoring & Alert System is a Python-based
monitoring application designed to monitor multiple sensor
readings and identify abnormal conditions using predefined
threshold values.

The system monitors:
- Temperature
- Humidity
- Voltage
- Current

It classifies sensor conditions as NORMAL, WARNING, or CRITICAL
and generates appropriate alerts.

## 🚀 Features

- Real-time sensor reading input
- Temperature monitoring
- Humidity monitoring
- Voltage monitoring
- Current monitoring
- Threshold-based status detection
- NORMAL / WARNING / CRITICAL classification
- Automatic alert generation
- Multiple sensor monitoring cycles
- Timestamp for sensor readings
- Average, minimum and maximum calculations
- Menu-driven interface
- Invalid menu choice handling
